# Путь к B1 — платформа индивидуальных занятий

Статический веб-сайт (без сервера и сборки): виртуальный ассистент **Эми** знакомится с ученицей, определяет стартовый уровень, составляет план и ведёт её к B1 — каждый день выдаёт короткий план, повторяет пройденное и проверяет результат.

## Как открыть

- Локально: открыть `index.html` в браузере (работает и с `file://`).
- В интернете: загрузить папку `b1-platform/` на любой статический хостинг (GitHub Pages, Netlify, Vercel). Ничего собирать не нужно.
- Прогресс хранится в браузере ученицы (`localStorage`). Чтобы преподаватель его увидел: «Ещё → Скачать прогресс» → файл `.json` → «Кабинет преподавателя» (`#/teacher`) → «Загрузить отчёт».

## Что делает платформа

| Этап | Что происходит |
|---|---|
| Знакомство | Чат-опросник (16 вопросов): цели, трудности, дни и минуты в неделю, удобное время, формат, занятия с преподавателем, срок, стиль общения |
| Диагностика | 30 вопросов A1 → B1, определяет стартовый этап; темы, где была ошибка, возвращаются как «пробелы» |
| План | Дорожная карта из 4 этапов, оценка срока по режиму ученицы, честное сравнение с дедлайном, `.ics`-календарь |
| Каждый день | Ассистент собирает план под её минуты: повторение слов → повторение грамматики → новый урок → проверка |
| Закрепление | Слова — 5 «коробок» (1/3/7/16/35 дней), грамматика — повторения через 1/3/7/14/30 дней |
| Контроль | Недельная проверка, итоговый тест каждого этапа (проходной балл 70 %) |
| Письмо | 9 проектов, тексты сохраняются для преподавателя |
| Для преподавателя | Сводка, слабые темы, письменные работы, «что обсудить на следующем занятии» |

## Дорожная карта и книги

Нумерация уроков совпадает с книгами. Тексты книг в платформу **не** копируются: правила и упражнения написаны заново, а на страницах книг ученица работает по номерам уроков.

1. **A1 «Фундамент»** — Essential Grammar in Use, уроки 1–15 + Vocabulary Elementary, темы 1–13
2. **A2 «Основы общения»** — Essential Grammar 16–52 + Vocabulary 14–37
3. **A2+ «Уверенный A2»** — Essential Grammar 53–115 + Vocabulary 38–60
4. **B1 «Финишная прямая»** — 48 избранных уроков из Murphy, English Grammar in Use + письменные проекты

Интерактивные уроки (правило, упражнения, автопроверка): 67 уроков, 536 упражнений. Остальные уроки идут «по книге»: ученица читает урок, делает упражнения в книге, сверяется с ключом и отмечает результат.

## Как добавить урок

В `js/data/lessons-*.js` (или новый файл, подключённый в `index.html`):

```js
JP.L('eg-29', 'A2', `<p>Правило в HTML. <q>Пример</q> — по клику озвучивается.</p>`, [
  JP.gap('I ___ help you.', 'will'),                       // вписать слово (варианты через |)
  JP.mc('Выбери вариант', ['a', 'b', 'c'], 1, 'Пояснение'), // индекс верного ответа
  JP.ord('Собери это предложение.')                         // составить из слов
], 'Задание для письма (необязательно)');
```

Номер урока (`eg-N` или `mu-N`) должен существовать в `curriculum.js`. Проверка: `node tools/validate.js`.

## Ограничения и следующие шаги

- Платформа не заменяет живого преподавателя: говорение и проверку писем делает он. Платформа готовит почву и показывает, что обсуждать.
- Данные хранятся на устройстве. Чтобы преподаватель видел прогресс онлайн и Эми могла писать ученице сама, нужен сервер (например, Supabase) — это отдельный следующий шаг.
- Ассистент работает по сценариям, не LLM. Подключение языковой модели (разбор писем, диалог) возможно через серверную функцию, без ключей в браузере.
- Уровень по шкале CEFR платформа оценивает ориентировочно; для официального подтверждения нужен экзамен (например, Cambridge B1 Preliminary).

## Вход, регистрация и кабинет преподавателя

- **Регистрация ученика по email.** Преподаватель создаёт одноразовый код и отправляет ссылку-приглашение `https://<сайт>/#/login?code=XXXXXXXXXX`. Ученик вводит код, имя, email и пароль (от 8 символов); Supabase Auth отправляет письмо для подтверждения адреса. Пока почта не подтверждена, войти нельзя, а код не расходуется. После подтверждения ученик входит по email и паролю с любого устройства; прогресс подтягивается с сервера.
- **Забыли пароль.** На экране входа «Забыли пароль?» отправляет письмо со ссылкой для нового пароля. Смена пароля доступна в «Ещё → Аккаунт».
- **Ученики, пришедшие до email** (старый вход по токену или по логину): в «Ещё → Аккаунт» блок «Привяжите email». Прогресс сохраняется. Вход по старому логину продолжает работать, пока email не привязан.
- **Сброс доступа.** В карточке ученика кнопка «Сброс доступа (код)». Ученик регистрируется по этому коду с новым email, прогресс остаётся у того же ученика.
- **Защита.** Данные ученика доступны только ему (по привязке к подтверждённому email) и преподавателю; все таблицы под RLS; код одноразовый, неверный код замедляется. Старый вход по логину блокируется на 15 минут после 5 неверных попыток.
- **Кабинет** (`/#/admin`, вход по email и паролю Supabase Auth, доступ у email из таблицы `b1_teachers`): разделы «Обзор», «Ученики» (поиск, сортировка, фильтры, сравнение), «Коды» (создание, пачки до 50, приглашения, выгрузка .csv, кто воспользовался), карточка ученика с дашбордом и отчётом для занятия.
- **База:** Supabase, таблицы `b1_teachers`, `b1_students`, `b1_sessions`, `b1_invites` под RLS; функции `b1_check_code`, `b1_claim`, `b1_claim_legacy`, `b1_me`, `b1_push` (и старые `b1_login`, `b1_change_password`).
- **Настройки Supabase, которые нужны для писем:** Authentication → URL Configuration: добавить адрес сайта в Redirect URLs (чтобы ссылка из письма открывала платформу); Authentication → Emails: для реальной работы настроить собственный SMTP (встроенная отправка сильно ограничена по числу писем).
- **Тесты:** `node tools/validate.js`, `node tools/cloud-test.js` (регистрация, вход, привязка email, кабинет на имитации Supabase), `node tools/verbs-test.js`, `node tools/smoke-test.js`.
